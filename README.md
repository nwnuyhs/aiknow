# aiknow — a vertical search engine for AI tools

**👉 [www.aiknow.cc](https://www.aiknow.cc)** · free · no sign-up · English & 中文

[![aiknow](https://www.aiknow.cc/opengraph-image)](https://www.aiknow.cc)

aiknow is an **AI vertical search engine**: instead of browsing a directory, you describe the task in plain words and it finds the right AI tool.

> "open-source TTS with an API" · "free AI coding agent for Windows" · "MCP server for Postgres" · "AI that turns a PDF into slides"

It understands what you mean (task, free / open-source / has API, platform, country, model family), searches **3,600+ curated AI tools**, and an AI recommendation tells you which result fits best and why.

Every entry is a real tool with a working link, a short summary, tags and facets (free, open source, has API, platforms, country).
